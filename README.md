# 🐍 Python Learning Journey

Welcome to my Python learning journey!

This repository documents my journey of learning Python by building practical projects from beginner to advanced.

Instead of only studying theory, I learn every new concept by creating real projects. Each project introduces new programming concepts while reinforcing everything learned in previous projects.

My goal is to build strong Python fundamentals before moving on to Django, databases, APIs, and real-world backend development.
